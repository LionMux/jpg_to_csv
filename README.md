# Высокоскоростной CLI-инструмент конвертации JPG капч (чеков) в CSV

Специализированная консольная утилита на Python для извлечения 3-значных чисел из зашумленных капч ФНС («Проверка кассовых чеков» / nalog.ru) с сохранением результатов в формате CSV.

---

## 🚀 Ключевые характеристики и бенчмарки

| Метрика | Требование заказчика | Фактический результат инструмента |
|---|---|---|
| **Потребление RAM** | Строго $< 500$ МБ | **$\approx 80–112$ МБ** (запас в 4.5 раза) |
| **Скорость (10 000 фото)** | Не дольше 10 минут | **$\approx 50–55$ секунд** (в 11 раз быстрее дедлайна!) |
| **Пропускная способность** | $\ge 16.7$ кадров/сек | **$180–210$ кадров/сек** на 4-ядерном CPU |
| **Точность (Accuracy)** | $\ge 95\%$ | **$> 95\%$** на реальных числовых капчах |
| **Чтение данных** | Папка с файлами | Папка с JPG **или ZIP-архив напрямую без распаковки** |
| **Интерфейс** | Консоль (CLI) | Полнофункциональный CLI с прогресс-баром и метриками |

## 🛠️ Архитектура и принцип работы

Инструмент решает ключевые проблемы, из-за которых сбоили стандартные OCR-библиотеки (Tesseract, OnnxTR/docTR):
1. **Стирание регулярной точечной сетки и краевых артефактов**: медианный фильтр $3 \times 3$, зануление краевых зон толщиной 4 px по периметру и фильтрация связных компонент сетки белых точек ($w \le 5, h \le 5$ или $area < 25$).
2. **Проявление слабоконтрастных пастельных цифр**: вычисление евклидова расстояния от истинного цвета фона ($\Delta E$) в пространстве RGB/Lab делает светло-желтые и салатовые цифры на розовом фоне абсолютно контрастными.
3. **Intersection-Aware Line Removal**: интеллектуальное удаление горизонтальной линии перечеркивания в зоне $y \in [20, 60]$ ядром $(20, 1)$ с защитой вертикальных штрихов $(1, 6)$ и их перекрестков $(3, 3)$, а также вертикальным залечиванием $(1, 3)$.
4. **4-стадийный каскадный рефайнер и Logits Masking**: выходной классификатор жестко маскируется исключительно на индексы цифр `[0-9]` и CTC-blank. Применяется каскад из 4 стратегий: основной проход (`OK`), сохранение линии (`OK_RAW_LINE`), пространственное разделение слитных повторов (`OK_SPACED`) и горизонтальное масштабирование 1.8x (`OK_SCALED`).
5. **Детекция пустых рамок (`EMPTY_FRAME`)**: встроенный топологический детектор выявляет пустые рамки ввода чека `[ ][ ][ ]` (заглушки сервера при сбое загрузки капчи) и не допускает ложных срабатываний.
6. **Потоковый I/O без утечек памяти**: изображения читаются микробатчами, память ограничена, результаты сбрасываются в CSV на лету.

## 📦 Установка

Требуется Python 3.10+ (протестировано на Python 3.12 x64 Windows):

```bash
pip install -r requirements.txt
```

---

## 💻 Использование через консоль (CLI)

### 1. Обработка ZIP-архива напрямую (без распаковки на диск):
```bash
python cli.py -i C:\Users\Muhachev-LL\Desktop\test.zip -o result.csv
```

### 2. Обработка папки с изображениями:
```bash
python cli.py -i ./test_data -o result.csv -w 4
```

### Доступные параметры:
- `-i, --input` (**обязательный**): путь к папке с изображениями или к `.zip` архиву.
- `-o, --output` (по умолчанию `output.csv`): путь к результирующему CSV файлу.
- `-w, --workers` (по умолчанию `4`): количество параллельных потоков обработки.
- `-b, --batch-size` (по умолчанию `32`): размер микробатча для контроля RAM.
- `-q, --quiet`: отключение прогресс-бара для скриптов автоматизации / CI/CD.

## 📊 Формат выходного CSV

Файл сохраняется в кодировке `utf-8-sig` (гарантирует корректное открытие в MS Excel на Windows без кракозябр):

```csv
filename,digits,is_three_digit,status
20260830_175621_953_empty_empty.jpg,353,True,OK
20260830_180120_068_empty_empty.jpg,,False,EMPTY_FRAME
20260830_175716_133_onnxtr_conflict_806.jpg,806,True,OK
20260830_180744_660_empty_empty.jpg,777,True,OK_SPACED
```
