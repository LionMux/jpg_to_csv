# Документация консольного интерфейса (CLI Reference)

## Общие сведения

Консольная утилита `cli.py` предназначена для автоматизированного пакетного распознавания 3-значных чисел из зашумленных капч ФНС (сервис проверки кассовых чеков) и сохранения результатов в файл CSV.

Инструмент спроектирован для высоконагруженной обработки данных в условиях жестких ресурсных ограничений:
- **Потребление оперативной памяти**: $\le 115$ МБ RAM (при нормативе $< 500$ МБ).
- **Производительность**: $180–210$ изображений в секунду (обработка 10 000 фото занимает $\approx 50$ секунд при нормативе $\le 10$ минут).
- **Потоковый ввод/вывод**: поддержка обработки файлов напрямую из `.zip` архивов без промежуточной распаковки на диск, потоковая запись в CSV блоками.

---

## Синтаксис команды

```bash
python cli.py -i <ИСТОЧНИК> [-o <ВЫХОДНОЙ_ФАЙЛ>] [-w <ПОТОКИ>] [-b <РАЗМЕР_БАТЧА>] [-q]
```

---

## Параметры командной строки

| Флаг | Полное имя | Тип | По умолчанию | Описание |
|---|---|---|---|---|
| `-i` | `--input` | `Path` | *Обязательный* | Путь к входному источнику данных. Может указывать либо на **папку с изображениями**, либо на **`.zip` архив** напрямую. |
| `-o` | `--output` | `Path` | `output.csv` | Путь к результирующему CSV-файлу. Если родительские папки не существуют, они создаются автоматически. |
| `-w` | `--workers` | `int` | `min(4, CPU_COUNT)` | Количество параллельных рабочих потоков для декодирования и инференса. Рекомендуется от 2 до 8. |
| `-b` | `--batch-size` | `int` | `32` | Количество изображений в одном микробатче. Регулирует баланс между скоростью I/O и удержанием памяти RAM в пределах $\le 120$ МБ. |
| `-q` | `--quiet` | `flag` | `False` | Тихий режим. Отключает вывод прогресс-бара и статистики в консоль (рекомендуется для скриптов автоматизации, cron и CI/CD). |
| `-h` | `--help` | `flag` | — | Вывод встроенной контекстной справки с примерами и завершение работы. |

## Поддерживаемые форматы входных данных

### 1. Обработка ZIP-архива напрямую (Рекомендуется)
Если аргумент `-i` указывает на файл с расширением `.zip`:
- Утилита открывает архив в режиме потокового чтения через `zipfile.ZipFile`.
- Изображения считываются микробатчами напрямую в оперативную память и декодируются в ОЗУ через `cv2.imdecode`.
- **Никаких временных файлов на жесткий диск не записывается**. Это предотвращает износ SSD и ускоряет обработку в 2–3 раза.

### 2. Обработка каталога на диске
Если аргумент `-i` указывает на директорию:
- Утилита выполняет быстрое нерекурсивное сканирование каталога через `os.scandir`.
- Фильтруются файлы со следующими расширениями: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`.

## Формат выходного CSV-файла

Файл сохраняется с кодировкой **`utf-8-sig`** (UTF-8 с меткой порядка байтов BOM). Это гарантирует, что файл корректно откроется в Microsoft Excel на любых версиях Windows без искажения кириллицы и спецсимволов.

### Структура колонок:

```csv
filename,digits,is_three_digit,status
```

1. **`filename`** (*строка*): имя файла изображения (например, `20260830_175621_953_empty_empty.jpg`).
2. **`digits`** (*строка*): извлеченное число (только цифры `0-9`). Если цифры не найдены или на изображении пустая заглушка — пустая строка.
3. **`is_three_digit`** (*булево: `True`/`False`*): признак успешного распознавания строго трехзначного числа (`len(digits) == 3`).
4. **`status`** (*строка*): детальный диагностический статус обработки изображения.

### Возможные статусы (`status`):

| Статус | Описание | Значение `is_three_digit` |
|---|---|---|
| **`OK`** | Число из 3 цифр успешно распознано в первичном проходе с фильтрацией линии и залечиванием штрихов. | `True` |
| **`OK_SCALED`** | Число из 3 цифр успешно распознано после горизонтального масштабирования (Aspect Ratio Scaling 1.8x) для сжатых и узких символов. | `True` |
| **`OK_SPACED`** | Число из 3 цифр успешно распознано после применения пространственного разделения компонент (решение для повторяющихся цифр `777`, `811`, `440`). | `True` |
| **`OK_RAW_LINE`** | Число из 3 цифр успешно распознано в проходе с сохранением линии (для ультратонких шрифтов). | `True` |
| **`EMPTY_FRAME`** | Обнаружена пустая прямоугольная рамка формы ввода чека `[ ][ ][ ]` (заглушка сервиса ФНС при сбое генерации капчи, цифр нет). | `False` |
| **`PARTIAL`** | Обнаружено частичное число (1 или 2 цифры из-за экстремального повреждения штрихов). | `False` |
| **`EMPTY`** | Цифры не обнаружены (пустое изображение или шум). | `False` |
| **`ERROR_DECODE`** | Файл поврежден и не может быть декодирован как валидное изображение. | `False` |

## Примеры использования

### Пример 1. Базовый запуск на ZIP-архиве
```bash
python cli.py -i C:\Users\Muhachev-LL\Desktop\test.zip -o results.csv
```

### Пример 2. Запуск на локальной папке в 8 параллельных потоков
```bash
python cli.py -i C:\Users\Muhachev-LL\Desktop\jpg_to_csv\test_data -o results.csv -w 8
```

### Пример 3. Запуск в фоновом/тихом режиме для скриптов автоматизации
```bash
python cli.py -i C:\Users\Muhachev-LL\Desktop\test.zip -o results.csv --quiet
```

### Пример 4. Настройка под слабое «железо» (RAM < 80 МБ)
Для машин с минимальным объемом оперативной памяти можно уменьшить размер батча и число потоков:
```bash
python cli.py -i C:\Users\Muhachev-LL\Desktop\test.zip -o results.csv -w 2 -b 16
```

## Диагностика и мониторинг в реальном времени

В процессе выполнения утилита выводит однострочный динамический индикатор:
```
[################----]  81.6% (736/902) | Скорость: 209.1 кадр/с | ETA: 00с | RAM: 109.3 МБ | 3-значных: 596
```
Параметры индикатора:
- **`[###---]`**: процент выполнения задачи.
- **`Скорость`**: текущий throughput в кадрах за секунду.
- **`ETA`**: расчетное время до окончания обработки.
- **`RAM`**: текущий объем Resident Set Size (RSS) памяти процесса.
- **`3-значных`**: счетчик успешно найденных трехзначных капч.

По завершении выводится подробный итоговый отчет с расчетом экстраполяции на 10 000 фото:
```
=================================================================
ИТОГОВЫЙ ОТЧЕТ ОБРАБОТКИ ДАТАСЕТА
=================================================================
Всего обработано изображений:    902
Обнаружено 3-значных чисел:      745 (82.6%)
Обнаружено пустых рамок чеков:   22
Затраченное время:               5.04 сек
Средняя скорость (Throughput):   178.9 изображений/сек
Пиковое потребление RAM:         109.6 МБ (лимит: 500 МБ)
Расчетное время на 10 000 фото:  55.9 сек (0.93 мин, лимит: 10 мин)
Результаты сохранены в CSV:      test_results.csv
=================================================================
```

## Коды возврата процесса (Exit Codes)

- **`0`**: Успешное завершение обработки.
- **`1`**: Ошибка валидации параметров (входной файл/каталог не найден, ошибка прав доступа, недопустимый формат).
